Payment gateways for Digital Wallets (Yape and Plin) and Bank Transfers (BCP, BBVA, Interbank, Scotiabank) with toggle buttons for Peru. (Free version).

== Description ==

This plugin allows you to integrate popular manual payment methods in Peru directly into your checkout process.

* Digital Wallets: Yape and Plin.
* Bank Transfers: BCP, BBVA, Interbank, Scotiabank.

The customer selects their method and receives the instructions for payment. Compatible with High-Performance Order Storage (HPOS).

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/transferencias-billeteras-peru` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to WooCommerce > Settings > Payments to configure your accounts.
